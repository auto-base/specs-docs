# Конфликтующие изменения в API проекта %product%

Начиная с версии %autobase-api-version% (версия спецификации %spec-version%) в публичном API проекта %product% изменится
политика обновления эндпоинтов и полей, теперь любые изменения будут происходить с выходом дополнительных уведомлений.

## Изменения, связанные с обновлением публичного API проекта %product%

Группа эндпоинтов `/case` помечается как deprecated и будет удалена в ближайшем будущем (не ранее 02.10.2025), взамен
предлагается использовать эндпоинты группы `/export`.

| Старые эндпоинты                   | Предлагаемая альтернатива                 | Описание эндпоинта                                     |
|------------------------------------|-------------------------------------------|--------------------------------------------------------|
| `/case/find`                       | `/export/case/find`                       | Поиск дел по заданному запросу                         |
| `/case/{case_uid}/available-calcs` | `/export/case/{case_uid}/available-calcs` | Получение доступных калькуляций по идентификатору дела |

## Подробные изменения в эндпоинте /export/case/find

Эндпоинт `/case/find` будет удалён из публичного API, его заменит `/export/case/find`.

В новом эндпоинте, при получении дела будут удалены следующие поля:

| Название поля        | Тип    | Описание                                                                                           |
|----------------------|--------|----------------------------------------------------------------------------------------------------|
| owner_uid            | string | Идентификатор клиента, которому принадлежит дело                                                   |
| owner_group_uid      | string | Идентификатор группы, которой видно дело в рамках клиента-владельца                                |
| assigned_client_uid  | string | Идентификатор клиента, который в настоящий момент оперирует с делом                                |
| assigned_group_uid   | string | Идентификатор группы, которой видно дело в рамках клиента, в настоящий момент оперирующего с делом |
| assigned_user_uid    | string | Идентификатор пользователя, который в настоящий момент оперирует с делом                           |
| is_available         | bool   | Признак доступности дела для данного пользователя                                                  |
| order_billing_type   | string | Тип биллингования дел                                                                              |
| created_by_client    | string | Идентификатор клиента, который создал дело                                                         |
| customer_code        | string | Идентификатор клиента, заказчика дела                                                              |
| customer_name        | string | Наименование клиента, заказчика дела                                                               |
| owner_code           | string | Код клиента (Владелец дела)                                                                        |
| owner_name           | string | Наименование клиента (Владелец дела)                                                               |
| assigned_client_code | string | Код клиента (Который в данный момент оперирует с делом)                                            |
| stage                | string | Стадия дела (Системное поле)                                                                       |
| template_code        | string | Код шаблона полей, на основе которого создано дело (Системное поле)                                |
| assigned_client_name | string | Наименование клиента (Который в данный момент оперирует с делом)                                   |
| available_operations | Object | Доступные операции по делу (Системное поле)                                                        |

Поля, которые будут выводиться в ответе нового эндпоинта:

| Название поля     | Тип             | Описание                             |
|-------------------|-----------------|--------------------------------------|
| uid               | string          | Уникальный идентификатор дела        |
| number            | string          | Номер дела                           |
| created_at        | string/datetime | Дата создания дела                   |
| updated_at        | string/datetime | Дата обновления дела                 |
| state             | string          | Состояние дела                       |
| phase             | string          | Фаза состояния дела                  |
| type              | string          | Тип дела (КАСКО / ОСАГО)             |
| grz               | string          | Государственный регистрационный знак | 
| recipient_company | string          | Компания получатель                  |
| wearout           | float           | Износ в деле                         |
| vehicle_age       | float           | Возраст автомобиля                   |
| customer_uid      | string          | Идентификатор заказчика              |
| last_calc_info    | string          | Информация о последней калькуляции   |
| vehicle           | object          | <a href="#vehicle">см. ниже</a>      |
| documents         | object          | <a href="#documents">см. ниже</a>    |

## Подробные изменения в эндпоинте /export/case/&#123;case_uid&#125;/available-calcs

Теперь в эндпоинте `/export/case/{case_uid}/available-calcs` не отображаются незавершенные (текущие) калькуляции (
расчёты).
